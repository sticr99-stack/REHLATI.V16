# رحلتي / Rehlati — v15.1 + طبقة السيرفر (v16-API)

نموذج أولي كامل لموقع حجز الطيران والفنادق والباقات — HTML + Tailwind CSS (بناء محلي) + JavaScript خالص، **ومربوط الآن بسيرفر حقيقي و API** (انظر `DEPLOY-AR.md` للنشر على استضافة حقيقية).

## النسخة المستضافة (سيرفر + API + قاعدة بيانات)

إلى جانب وضع file:// المحلي، هذه الصفحات مربوطة الآن بسيرفر Next.js يوفر:

- **بحث حي**: `/api/flights/search` و `/api/hotels/search` و `/api/packages/search` — نتائج مباشرة في صفحة النتائج (توست «نتائج مباشرة من سيرفر رحلتي»)، مع محرك Amadeus الحقيقي عند إضافة المفاتيح، ومحرك محاكاة بأسعار MAD بدونه.
- **حجوزات دائمة**: كل تأكيد حجز يُخزَّن في قاعدة بيانات السيرفر (إضافة إلى localStorage) — صفحة «رحلتي» تدمج حجوزات السيرفر تلقائياً والحذف يُزامَن بالاتجاهين.
- **حسابات حقيقية**: تسجيل الدخول ينشئ حساباً على السيرفر عند أول دخول (كلمة سر مشفرة scrypt + جلسة موقّعة HMAC).
- **وضع مزدوج آمن**: عند فتح الملفات محلياً (`file://`) أو عند سقوط السيرفر، يعمل الموقع محلياً كما كان تماماً — الجسر `js/api-bridge.js` يكتشف البيئة تلقائياً ولا يكسر شيئاً.

ملفات الطبقة الجديدة: `js/api-bridge.js` (جسر الواجهة) + `DEPLOY-AR.md` (دليل النشر: Vercel / VPS / Railway + تفعيل Amadeus). CSP في الصفحات توسّع بـ `'self'` فقط لسمح بجلب الـ API من نفس الأصل.

## التشغيل (بلا أي خطوة إعداد)

افتح **`index.html`** مباشرة في المتصفح (نقرة مزدوجة) — هذه الصفحة الرئيسية الشاملة التي تبدأ منها جولة المستخدم:

```
index.html  ←  نتائج البحث  ←  صفحات الحجز  ←  رحلتي
```

> **كل ملف HTML مكتفٍ بذاته**: تنسيق Tailwind مدمج داخل الصفحة نفسها — انسخ أي ملف منفرداً إلى أي مكان (سطح المكتب مثلاً) وافتحه مباشرة وسيعمل منسقاً بالكامل. مجلد `css/` مصدر بناء للصيانة فقط وغير ضروري للتشغيل. تحتاج اتصالاً بالإنترنت فقط لخطوط Google وFont Awesome.

## المزايا المشتركة

- **ثنائي اللغة AR/EN** مع قلب RTL/LTR كامل وقاموس i18n لكل صفحة (`?lang=ar|en`).
- **6 عملات** (MAD أساس + EUR/USD/SAR/AED/EGP) بتحويل فوري وحفظ محلي (`?cur=` أو `rehlati_cur`).
- **درج تنقل (Hamburger Drawer)** بعقد NameThatUI: `aria-expanded` متزامن، Escape/الحجاب يغلقان، قفل تمرير، إعادة تركيز، حصر Tab — ينزلق من جهة البداية (يسار LTR / يمين RTL).
- **خيار «Réservation visa»** في صفحات الحجز الثلاث: خانة اختيار فوق زر تأكيد الحجز تُصدر تلقائياً مستند PDF رسمي (فرنسي في الواجهة العربية / إنجليزي في الإنجليزية) بتفاصيل الحجز وشارة «غير مدفوع» — صالح للإرفاق في ملف طلب التأشيرة. مكتبة jsPDF مضمّنة داخل الصفحات فالإصدار يعمل أوفلاين، ومع بديل طباعة تلقائي عند أي خلل. الحجوزات ذات الخيار تحمل شارة «أغراض تأشيرة» في صفحة رحلتي.
- **QR التحقق وزر «تحميل PDF» (v15.1)**: رمز QR يحمل ملخص الحجز (المرجع/المسار/التواريخ/المسافرون/المبلغ) يظهر في صندوق النجاح وفي بطاقات «رحلتي» — يُمسح بكاميرا أي هاتف من الشاشة أو من الورق بعد الطباعة، والنقر عليه يكبّره في نافذة مخصصة للمسح من هاتف آخر. زر «تحميل PDF» في صندوق النجاح وفي كل بطاقة رحلة يعيد إصدار مستند الحجز الاحترافي نفسه في أي وقت دون إعادة الحجز.
- **التحصين الأمني (v15.1-sec)** — تدقيق اختراق شامل وإصلاحات دون تغيير أي وظيفة أو تصميم:
  1. **إصلاح ثغرات XSS** (مخزّن + منعكس): تعقيم كل القيم القادمة من الرابط (`?f=&to=&dest=`) ومن `rehlati_trips` قبل حقنها في `innerHTML` — في «رحلتي» (البطاقات والمرجع)، صفحة النتائج (ملخص البحث + شارة الوجهة)، صناديق نجاح الحجز الثلاثة، وبديل الطباعة في iframe — مع حراسة مفاتيح `__proto__/constructor` على جداول العملات والأنواع.
  2. **Content Security Policy** في كل صفحة: `script-src 'unsafe-inline'` فقط (كل السكربتات مضمّنة) + قوائم بيضاء للأنماط والخطوط (fonts.googleapis.com / fonts.gstatic.com / cdnjs) + حظر `connect-src/object-src/base-uri/form-action` — أي سكربت خارجي محقون يُحجب (مُثبت بالاختبار).
  3. **SRI (Subresource Integrity)** بصمة sha384 لـ Font Awesome 6.7.2 من cdnjs + `crossorigin` — أي تعديل على المكتبة من الـCDN يُرفض تلقائياً.
  4. **Referrer-Policy: no-referrer** (لا تسرّب معايير البحث للمواقع الخارجية عند الاستضافة) + **Frame-busting** ضد الحشر في إطار (Clickjacking).
  5. **خصوصية**: حذف البريد الإلكتروني من سجلات الكونسول في تسجيل الدخول (كلمة المرور لا تُخزَّن أصلاً — مُثبت بالاختبار).
- **لا دفع**: كل الحجوزات تجريبية وتُحفظ محلياً فقط؛ أزرار المزودين الخارجيين placeholder.
- بناء Tailwind محلي v3.4.17 (بلا CDN) لكل صفحة في `css/`.
