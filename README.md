## 📖 القصة

بدأت رحلتي كشريط بحث واحد بصيغة HTML — نموذج أولي صغير يُفتح من سطح المكتب. ثم نما صفحةً بعد صفحة: نتائج بحث، حجز طيران، حجز فنادق، باقات، صفحة «رحلتي» للحجوزات، تسجيل دخول، مستندات تأشيرة PDF، رموز QR تحقق… ثم جاءت القفزة الكبرى: **سيرفر حقيقي** بواجهات API وقاعدة بيانات، وربط بمزوّد رحلات عالمي (Duffel)، والنشر على Vercel، والترحيل إلى PostgreSQL سحابي على Neon لتحفظ الحجوزات **للأبد** — لا حتى يُطفأ الجهاز.

كل ذلك بلا إطار عمل في الواجهة: صفحات HTML مكتفية بذاتها، JavaScript خالص، وثنائية لغة (عربي RTL / إنجليزي LTR) بقلب كامل للاتجاه، وستّ عملات بتحويل فوري.

## 🏗️ المعمارية

```
                        ┌─────────────────────────────────────┐
                        │              Vercel                 │
  المتصفح 🌍  ─────────▶ │  صفحات ساكنة (public/*.html)        │
                        │  + طبقة API (Next.js App Router)    │
                        └───────┬──────────────┬──────────────┘
                                │              │
                 ┌──────────────▼──┐        ┌──▼───────────────┐
                 │  Neon Postgres  │        │   Duffel API     │
                 │  (Prisma ORM)   │        │  الطيران الحقيقي │
                 │  مستخدمون وحجوزات│       └──┬───────────────┘
                 └─────────────────┘           │ duffel_live_ (قريباً)
                        ┌──────────────────────▼─┐
                        │      Resend (v1.4)     │
                        │  تأكيدات الحجز بالبريد │
                        └────────────────────────┘
```

- **وضع مزدوج آمن**: جسر `js/api-bridge.js` يكتشف توفر السيرفر تلقائياً؛ عند فتح الصفحات محلياً أو سقوط السيرفر يعمل الموقع أوفلاين كما كان تماماً.
- **محرك بحث مرن**: Duffel عند توفر التوكن، وإلا محرك محاكاة داخلي بأسعار MAD — الموقع لا يتوقف أبداً.

## ✨ المزايا

| | |
|---|---|
| 🔍 | بحث طيران وفنادق وباقات بفلاتر وترتيب فعّالين |

## 🚀 التشغيل

```bash
cp .env.example .env      # ثم املأ: DATABASE_URL و JWT_SECRET (و DUFFEL_API_TOKEN و RESEND_API_KEY)
npm install
npm run dev               # http://localhost:3000
```

على Vercel: اربط المستودع، ضع متغيرات البيئة، والدفع إلى `main` ينشر تلقائياً.
